# Fonts

All webfonts are served locally.

- Hanken Grotesk: existing interface font.
- Albert Sans 500, Latin: the home phrase “Be well prepared with”, chosen as a visual alternative to Aeonik Soft. [Project](https://github.com/usted/Albert-Sans), [license](albertsans-OFL.txt).
- Instrument Serif Italic: “quizly” in the home heading, with inherited weight and -3px letter spacing. [Project](https://github.com/Instrument/instrument-serif), [license](instrument-serif-OFL.txt).

The heading fonts are distributed under SIL Open Font License 1.1. Their WOFF2 files come from the Google Fonts CSS API.

Reference for the Albert Sans alternative: [Aeonik Soft](https://cotypefoundry.com/our-fonts/aeonik-soft).
